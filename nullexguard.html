From email to intelligence —
in seconds.

01
Enter an email
Input any email address. NullexGuard hashes the query and fires it against the Dehashed API — one of the largest breach intelligence databases available.
02
Breach cross-reference
Results are pulled from 40B+ records across thousands of known breach sources — from massive dumps like RockYou and Collection #1 to targeted site breaches.
03
Identity enrichment
We extract and deduplicate associated usernames, names, phone numbers, IP addresses, and physical addresses discovered across all breach entries.
04
Credential signals
Where passwords appear in breach data, we show a partial reveal — first and last character only — letting you confirm exposure without surfacing usable credentials.

01 —
Live Dehashed Lookups
Every search hits the Dehashed API in real time — no cached or stale data. You're querying 40B+ breach records live.
02 —
Breach Source Grouping
Results are grouped by breach origin, so you can see exactly which databases exposed the email and what data each one contained.
03 —
Identity Extraction
Usernames, real names, phone numbers, IP addresses, and physical addresses are extracted and deduplicated across all breach entries automatically.
04 —
Credential Hints
Partial password reveals (first + last char) let you confirm credential exposure without displaying usable plaintext passwords to anyone.

Hash Intelligence
Leaked hashed passwords are captured and surfaced — useful for identifying hash types and assessing cracking risk during security assessments.

Expandable breach cards, summary stats, and identity panels make it easy to triage exposure quickly without wading through raw API output.
